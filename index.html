About this build

KOReader on iOS.

This project provides a downloadable IPA build of KOReader for iPhone and iPad, based on the community-maintained iOS port.

Based on hezi/koreader-ios
This build is based on the hezi/koreader-ios fork, which brings KOReader to Apple's mobile platforms. The source code and original project are available on GitHub.

Features

Read your way.

KOReader gives you extensive control over how your books and documents look and behave.

📚

Multiple Formats

Read EPUB, PDF, MOBI, CBZ, CBR and many other supported formats.

🎨

Highly Customizable

Customize fonts, margins, spacing, layout and many other reading options.

🔖

Highlights & Notes

Highlight passages, add notes and keep important parts of your books.

📖

Dictionaries

Look up words directly while reading and use dictionaries for language learning.

🧩

Plugins

Extend KOReader with plugins and customize your reading workflow.

⚡

Reader Focused

A distraction-free environment designed around reading rather than social features.

Installation

Install with AltStore.

Download the IPA from the latest GitHub Release and install it using AltStore on your iPhone or iPad.

1

Download the IPA

Open the latest release and download KOReader-iOS.ipa to your device or computer.

2

Open AltStore

Open AltStore on your iPhone or iPad and import the downloaded IPA.

3

Install KOReader

Select the IPA and let AltStore sign and install the application.

iPhone iPad iOS / iPadOS AltStore IPA
Important: This website distributes a community-built iOS/iPadOS version of KOReader. It is not an official Apple App Store application and is not presented as an official KOReader iOS release.
