## 📲 How to Install KOReader on iPhone or iPad

The `.ipa` generated by this project is intended for installation using a compatible iOS sideloading method.

### TrollStore

If your iPhone or iPad and iOS / iPadOS version support TrollStore:

1. Download the KOReader `.ipa`.
2. Open the IPA with TrollStore.
3. Select **Install**.
4. Launch KOReader from your Home Screen.

TrollStore support depends on your specific device and OS version.

### AltStore / SideStore / Sideloadly

You can also install the KOReader IPA using:

* AltStore
* SideStore
* Sideloadly
* Xcode with Apple signing

With a free Apple Developer account, sideloaded applications may require periodic re-signing according to Apple's current signing limitations.

## 🛠️ Automated KOReader iOS Build

This repository uses **GitHub Actions** to automatically build KOReader for iOS / iPadOS.

The build process is:

```text
KOReader iOS source
        ↓
GitHub Actions
        ↓
Build KOReader
        ↓
Generate IPA
        ↓
GitHub Actions Artifact
        ↓
GitHub Release
```

The goal is to make **KOReader iOS builds easier to obtain** without requiring every user to configure the complete development environment themselves.

### Run the build yourself

1. Fork this repository.
2. Open the **Actions** tab.
3. Select the KOReader iOS build workflow.
4. Run the workflow.
5. Wait for the build to finish.
6. Download the generated `.ipa`.
